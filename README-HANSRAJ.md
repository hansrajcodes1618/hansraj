# Hansraj Portfolio

Personalized animated React + TypeScript portfolio. The original animation components and styling have been retained.

## Run in VS Code
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open Terminal and run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal.

## Edit your content
- `src/data/portfolio.ts` — profile, contact links, education, skills, certificates, projects and copy.
- `public/assets/hansraj-portrait.png` — profile portrait.
- `public/assets/Hansraj_Resume.pdf` — starter resume.

Projects are marked as learning/in progress where appropriate. The LinkedIn URL currently uses the GitHub URL you supplied; replace it with your real LinkedIn profile URL when available.
